How to use LonelyFE7.exe:

Name your clean copy of Fire Emblem (U) to FE7.gba and place it in the same directory as LonelyFE7.exe then run the exe. You will see a console appear and depending on the speed of your computer there might be a little bit of a delay before you see it start printing anything. Once it has everything loaded up it will start printing it's progress and it will load the ROM. This can also take a moment. You will be prompted whether or not you want to load external patches. If you want to load external patches type y then press enter.

If you don't load external patches the randomizer will patch the game with limited features as the FE Builder patches provide additional functionality to the randomizer. You don't have any reason not to install these patches as they are free. I just have a reason to not include them in my exe because they are a part of FE Builder which is a licensed software.

If you did not have a settings.txt file in the directory with the exe then it will randomize the game with the default settings. If you have never played this randomizer before then you might want to try playing it with the default settings before opening the config.html page because the config menu does contain spoilers for features that appear in the randomizer.

How to use Config.html:

You will be able to use this page to configure some options for the randomizer and then save a settings.txt file which your browser will most likely download to your Downloads folder on your PC. You will then be able to place the generated settings.txt in the same folder as LonelyFE7.exe and it will randomize based on the configured defined in settings.txt.

If you have a settings.txt file in the same directory as Config.html when you load the page it will load the configuration from that file. You will then be able to re-configure the randomizer but you will need to generate a new settings.txt file and use the new file for the changes to take effect.

If you find you need to re-create the settings file a lot because you want to make frequent changes to the randomizer settings it might be useful to place the Config.html and LonelyFE7.exe in the Downloads folder where your browser saves the settings.txt file to so you don't need to move it around as much.

Tips for new players:

If you are playing the randomizer for the first time and you are using the default settings there are few things that can be good to know.

The Global Ranges, Display Growths, and Disable Tutorials patches from FE Builder will be installed if you chose to load external patches.

Any units you lose in combat will send their items to convoy so don't worry about losing your premium items along with your unit.

You will be able to access the convoy in battle preps during Lyn Mode and any items you had in Lyn Mode will be available in the convoy when you get Merlinus in Hector and Eliwood modes.

If you complete Lyn Mode you can fork your save after the Mode Select screen and your Lyn Mode chapter 10 save can then be used to go back to the Mode Select screen if you load it later. This will allow you to carry your Lyn Mode progress to a new route if you decide to change modes.

You can use the select button to cycle through the Torch, Unlock and Restore staves while hovering over the item in the Items menu.

Have fun!

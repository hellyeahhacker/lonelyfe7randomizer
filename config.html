Help
This page can be used to configure the randomizer settings. You will be able to generate a settings.txt file that you can download at the bottom of the page then place in the folder with LonelyFE7.exe. I strongly advise that you don't attempt to edit the settings file by hand as it can crash the randomizer or make the generated ROM unstable. Click "Help" in the corner of this box for more tips on using this page.
